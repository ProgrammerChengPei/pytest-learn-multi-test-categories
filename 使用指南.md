# Pytest-VIU-Design 使用指南 / Usage Guide

本文档详细介绍如何使用pytest-viu-design测试框架。

This document provides detailed instructions on how to use the pytest-viu-design testing framework.

---

## 快速开始 / Quick Start

### 1. 安装依赖 / Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. 生成Excel模板 / Generate Excel Template

```bash
python scripts/create_template.py
```

这会在 `templates/` 目录下生成 `test_report_template.xlsx` 文件。

This will generate the `test_report_template.xlsx` file in the `templates/` directory.

### 3. 运行测试 / Run Tests

```bash
# 运行所有测试 / Run all tests
pytest tests/ -v

# 运行特定测试文件 / Run specific test file
pytest tests/example_testcase_mapping.py -v

# 运行特定类型的测试 / Run specific type of tests
pytest tests/ -v -m flash
pytest tests/ -v -m interface
pytest tests/ -v -m function
pytest tests/ -v -m performance
```

### 4. 查看报告 / View Reports

测试运行后，Excel报告会自动生成在 `reports/` 目录下，文件名格式为 `test_report_YYYYMMDD_HHMMSS.xlsx`。

After running tests, the Excel report will be automatically generated in the `reports/` directory with the filename format `test_report_YYYYMMDD_HHMMSS.xlsx`.

## 测试用例中文名映射 / Test Case Chinese Name Mapping

### 为什么需要中文名映射？

实现用例设计（Excel）和用例脚本（Python）的对应关系。

To establish correspondence between test case design (Excel) and test scripts (Python).

### 使用方法 / Usage Methods

#### 方法1：使用 `@pytest.mark.chinese_name` 装饰器 / Method 1: Use Decorator

```python
import pytest

@pytest.mark.flash
@pytest.mark.chinese_name("测试abc")
def test_abc():
    """测试abc"""
    assert True
```

#### 方法2：使用中文文档字符串 / Method 2: Use Chinese Docstring

```python
import pytest

@pytest.mark.interface
def test_api_login():
    """API登录测试"""
    assert True
```

### Excel模板配置 / Excel Template Configuration

在Excel模板的"测试用例 TestCases"工作表中：
- **B列**: 测试用例名称（填写中文名，如"测试abc"）
- **J列**: 测试结果（自动填充"通过"/"失败"/"跳过"）

示例 / Example:
| 行号 | B列（测试用例名称） | ... | J列（测试结果） |
|------|---------------------|-----|----------------|
| 2 | 测试abc | ... | 通过（自动填充） |
| 3 | 连接设备 | ... | 通过（自动填充） |

### JSON配置文件 / JSON Configuration

在 `configs/report_config_with_testcases.json` 中配置：

```json
{
  "测试用例 TestCases": {
    "type": "testcase_mapping",
    "name_column": "B",
    "result_column": "J",
    "result_mappings": {
      "passed": "通过",
      "failed": "失败",
      "skipped": "跳过"
    }
  }
}
```

## 测试依赖管理 / Test Dependency Management

框架自动管理测试依赖链：
Flash → Interface → Function → Performance

The framework automatically manages the test dependency chain:
Flash → Interface → Function → Performance

### 自动依赖规则 / Automatic Dependency Rules

- **接口测试（interface）** 自动依赖所有刷写测试（flash）通过
- **功能测试（function）** 自动依赖所有接口测试（interface）通过
- **性能测试（performance）** 自动依赖所有功能测试（function）通过

### 示例 / Example

```python
# Flash测试 / Flash test
@pytest.mark.flash
def test_connect_device():
    """连接设备"""
    assert connect() == "success"

# Interface测试会自动等待Flash测试通过
# Interface test automatically waits for Flash test to pass
@pytest.mark.interface
def test_api_login():
    """API登录测试"""
    assert api_call().success

# Function测试会自动等待Interface测试通过
# Function test automatically waits for Interface test to pass
@pytest.mark.function
def test_user_registration():
    """用户注册流程"""
    assert register().success

# Performance测试会自动等待Function测试通过
# Performance test automatically waits for Function test to pass
@pytest.mark.performance
def test_response_time():
    """响应时间测试"""
    duration = measure_time()
    assert duration < 0.1
```

## 工作原理 / How It Works

### 钩子自动化 / Hook Automation

框架使用以下pytest钩子实现完全自动化：
The framework uses the following pytest hooks for complete automation:

| 钩子 / Hook | 功能 / Function |
|------------|---------------|
| `pytest_sessionstart` | 初始化报告生成器 / Initialize report generator |
| `pytest_runtest_setup` | 检查测试依赖 / Check test dependencies |
| `pytest_runtest_logreport` | 收集测试结果 / Collect test results |
| `pytest_runtest_makereport` | 更新测试状态 / Update test status |
| `pytest_collection_modifyitems` | 自动添加依赖标记 / Auto-add dependency markers |
| `pytest_sessionfinish` | 生成Excel报告 / Generate Excel report |

### 数据流程 / Data Flow

1. 测试开始 → 初始化报告生成器 / Test starts → Initialize report generator
2. 收集测试 → 提取marker和中文名 / Collect tests → Extract markers and Chinese names
3. 运行测试 → 检查依赖 → 执行测试 / Run tests → Check dependencies → Execute tests
4. 收集结果 → 自动记录到生成器 / Collect results → Auto-record to generator
5. 测试结束 → 生成Excel报告 / Test ends → Generate Excel report

## 常见问题 / FAQ

### Q: 为什么我的测试被跳过了？/ Why are my tests being skipped?

A: 检查依赖关系。如果Flash测试未通过，所有Interface、Function、Performance测试都会被跳过。

Check dependencies. If Flash tests fail, all Interface, Function, and Performance tests will be skipped.

### Q: 如何禁用自动依赖？/ How to disable automatic dependencies?

A: 可以在测试文件中不使用 `@pytest.mark.flash`、`@pytest.mark.interface` 等marker，或者修改 `conftest.py` 中的 `pytest_collection_modifyitems` 钩子。

You can avoid using `@pytest.mark.flash`, `@pytest.mark.interface`, etc. markers, or modify the `pytest_collection_modifyitems` hook in `conftest.py`.

### Q: 如何自定义Excel报告格式？/ How to customize Excel report format?

A: 两种方式：
1. 直接编辑 `templates/test_report_template.xlsx`
2. 修改 `configs/report_config_with_testcases.json` 配置

Two ways:
1. Directly edit `templates/test_report_template.xlsx`
2. Modify `configs/report_config_with_testcases.json` configuration

### Q: 中文提取不工作？/ Chinese name extraction not working?

A: 确保使用正确的方式：
1. 使用 `@pytest.mark.chinese_name("中文名")` 装饰器
2. 或确保文档字符串第一行是中文

Ensure correct usage:
1. Use `@pytest.mark.chinese_name("Chinese Name")` decorator
2. Or ensure first line of docstring is in Chinese
