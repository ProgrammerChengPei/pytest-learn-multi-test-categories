# 钩子驱动的全自动化测试框架

## 概述 / Overview

本文档介绍如何使用pytest钩子实现完全自动化的测试框架，包括：
- 自动Excel报告生成
- 自动测试依赖管理
- 自动测试状态管理
- 自动测试日志记录

所有功能均通过钩子实现，无需在测试代码中手动添加任何报告或状态管理代码。

## 钩子架构图 / Hook Architecture Diagram


## 一、自动Excel报告生成 / Automatic Excel Report Generation

### 1.1 pytest_sessionstart - 初始化报告生成器

```python
def pytest_sessionstart(session):
    """
    测试会话开始时自动初始化报告生成器
    """
    from src.excel_report import ExcelReportGenerator

    # 创建报告输出目录
    output_dir = project_root / "reports"
    output_dir.mkdir(exist_ok=True)

    # 初始化报告生成器
    generator = ExcelReportGenerator(output_dir)
    generator.start()

    # 存储到session对象中，供其他钩子使用
    session.config.excel_report_generator = generator
    session.config.session_start_time = time.time()
```

**作用 / Purpose:**
- 测试会话开始时自动执行
- 创建报告输出目录
- 初始化Excel报告生成器
- 将生成器存储到session中供其他钩子使用

### 1.2 pytest_runtest_logreport - 自动收集测试结果

```python
def pytest_runtest_logreport(report):
    """
    每个测试完成后自动收集结果
    """
    # 只在测试完成时收集结果
    if report.when == 'call':
        generator = report.session.config.excel_report_generator

        # 从测试节点获取测试类别
        test_node = report.node
        test_type = None
        for marker_name in ['flash', 'interface', 'function', 'performance']:
            if test_node.get_closest_marker(marker_name):
                test_type = marker_name
                break

        if test_type:
            # 构建测试结果字典
            test_result = {
                'name': report.node.name,
                'category': test_type,
                'status': 'passed' if report.passed else 'failed' if report.failed else 'skipped',
                'duration': report.duration,
                'message': str(report.longrepr) if not report.passed else '',
                'file': str(test_node.fspath),
                'line': test_node.lineno
            }

            # 性能测试额外信息
            if test_type == 'performance':
                if hasattr(report, 'user_properties'):
                    for key, value in report.user_properties:
                        if key == 'metric':
                            test_result['metric'] = value
                        elif key == 'value':
                            test_result['value'] = value

            # 自动添加到报告生成器
            generator.add_test_result(test_result)
```

**作用 / Purpose:**
- 每个测试完成后自动执行
- 自动提取测试名称、状态、耗时、消息等信息
- 自动识别测试类型（flash/interface/function/performance）
- 自动将结果添加到Excel报告

**使用示例 / Usage Example:**

测试代码中完全不需要添加报告代码：

```python
# tests/interface_tests/test_interface.py
import pytest

@pytest.mark.interface
```

### 1.3 pytest_sessionfinish - 自动生成报告

```python
def pytest_sessionfinish(session, exitstatus):
    """
    测试会话结束时自动生成Excel报告
    """
    generator = getattr(session.config, 'excel_report_generator', None)
    session_start_time = getattr(session.config, 'session_start_time', None)

    if generator and session_start_time:
        generator.stop()

        # 生成带时间戳的报告文件名
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        filename = f"test_report_{timestamp}.xlsx"

        # 自动生成报告
        report_path = generator.generate_report(filename)

        # 打印统计信息
        total_tests = len(generator.test_results)
        passed_tests = len([r for r in generator.test_results if r.get('status') == 'passed'])
        failed_tests = len([r for r in generator.test_results if r.get('status') == 'failed'])
        skipped_tests = len([r for r in generator.test_results if r.get('status') == 'skipped'])

        print(f"\n测试统计:")
        print(f"  总数: {total_tests}")
        print(f"  通过: {passed_tests} ({passed_tests/total_tests*100:.1f}%)" if total_tests > 0 else f"  通过: {passed_tests}")
        print(f"  失败: {failed_tests} ({failed_tests/total_tests*100:.1f}%)" if total_tests > 0 else f"  失败: {failed_tests}")
        print(f"  跳过: {skipped_tests}")
        print(f"  耗时: {generator.end_time - session_start_time:.2f}s")
        print(f"\n报告路径: {report_path}")
```

**作用 / Purpose:**
- 测试会话结束时自动执行
- 自动生成带时间戳的Excel报告文件
- 自动计算并打印测试统计信息
- 完全自动化，无需任何手动调用

## 二、自动测试依赖管理 / Automatic Test Dependency Management

### 2.1 pytest_collection_modifyitems - 自动添加依赖标记

```python
def pytest_collection_modifyitems(config, items):
    """
    自动添加测试依赖标记
    """
    # 定义依赖映射
    dependency_mapping = {
        'interface': 'test_flash_complete',
        'function': 'test_interface_complete',
        'performance': 'test_function_complete'
    }

    for item in items:
        # 检查测试类型标记
        for marker_name in ['interface', 'function', 'performance']:
            if item.get_closest_marker(marker_name):
                # 自动添加依赖标记
                dependency_name = dependency_mapping.get(marker_name)
                if dependency_name:
                    item.add_marker(
                        pytest.mark.dependency(
                            depends=[dependency_name],
                            name=f"{marker_name}_auto_dep_{item.name}"
                        )
                    )
                break

    # 按测试类型排序（可选）
    phase_order = {
        'flash': 0,
        'interface': 1,
        'function': 2,
        'performance': 3
    }

    def get_test_order(item):
        for marker_name, order in phase_order.items():
            if item.get_closest_marker(marker_name):
                return order
        return 99

    items.sort(key=get_test_order)
```

**作用 / Purpose:**
- 测试收集完成后自动执行
- 自动为interface/function/performance测试添加依赖标记
- 自动按测试类型排序，确保flash测试先执行
- 无需在每个测试上手动添加`@pytest.mark.dependency`

**依赖规则 / Dependency Rules:**
- 接口测试 (interface) → 依赖刷写测试完成
- 功能测试 (function) → 依赖接口测试完成
- 性能测试 (performance) → 依赖功能测试完成

### 2.2 pytest_runtest_setup - 自动检查依赖

```python
def pytest_runtest_setup(item):
    """
    每个测试运行前自动检查依赖
    """
    # 检查测试类型
    test_type = None
    for marker in ['interface', 'function', 'performance']:
        if item.get_closest_marker(marker):
            test_type = marker
            break

    if not test_type:
        return  # 不是需要依赖检查的测试

    # 获取test_state fixture
    test_state = None
    try:
        if hasattr(item, '_fixtureinfo'):
            fixturedef = item._fixtureinfo.name2fixturedefs.get('test_state')
            if fixturedef:
                test_state = fixturedef[0].cached_result
                if test_state:
                    test_state = test_state[0]
    except Exception:
        pass

    if not test_state:
        return

    # 检查依赖，自动跳过未满足依赖的测试
    skip_reason = None
    if test_type == 'interface' and not test_state.flash_test_passed:
        skip_reason = "Flash test has not passed yet. Skipping dependent tests."
    elif test_type == 'function' and not test_state.interface_test_passed:
        skip_reason = "Interface test has not passed yet. Skipping dependent tests."
    elif test_type == 'performance' and not test_state.function_test_passed:
        skip_reason = "Function test has not passed yet. Skipping dependent tests."

    if skip_reason:
        pytest.skip(skip_reason)
```

**作用 / Purpose:**
- 每个测试运行前自动执行
- 自动检查前置测试是否通过
- 自动跳过未满足依赖的测试
- 无需手动编写依赖检查代码

### 2.3 pytest_runtest_makereport - 自动更新测试状态

```python
def pytest_runtest_makereport(item, call):
    """
    每个测试报告生成时自动更新测试状态
    """
    report = call.result if call else None

    if report and report.when == 'call' and report.passed:
        test_state = None

        # 获取test_state fixture
        try:
            if hasattr(item, '_fixtureinfo'):
                fixturedef = item._fixtureinfo.name2fixturedefs.get('test_state')
                if fixturedef:
                    test_state = fixturedef[0].cached_result
                    if test_state:
                        test_state = test_state[0]
        except Exception:
            pass

        # 自动更新测试完成状态
        if test_state:
            if item.get_closest_marker('flash'):
                test_state.mark_flash_passed()
            elif item.get_closest_marker('interface'):
                test_state.mark_interface_passed()
            elif item.get_closest_marker('function'):
                test_state.mark_function_passed()

    return report
```

**作用 / Purpose:**
- 测试报告生成时自动执行
- 自动更新测试状态管理器
- 标记flash/interface/function测试完成
- 无需手动调用`mark_*_passed()`

## 十一、故障排查 / Troubleshooting

### 11.1 报告未生成

**问题 / Issue:** 运行测试后没有生成Excel报告

**解决方案 / Solution:**
1. 检查是否有安装openpyxl：`pip install openpyxl`
2. 检查conftest.py中是否正确实现了钩子函数
3. 查看pytest输出是否有错误信息

### 11.2 测试依赖未生效

**问题 / Issue:** 依赖测试未通过时，后续测试仍然执行

**解决方案 / Solution:**
1. 检查是否正确添加了marker：`@pytest.mark.interface`
2. 检查pytest_collection_modifyitems钩子是否正常工作
3. 查看pytest输出中的依赖信息

### 11.3 性能指标未记录

**问题 / Issue:** 性能测试的指标没有出现在报告中

**解决方案 / Solution:**
1. 确保使用了`request.node.user_properties.append()`
2. 检查pytest_runtest_logreport钩子是否正确处理user_properties
3. 确保测试标记为`@pytest.mark.performance`

|----------------|------------------|
| 零配置报告 / Zero-config Reporting | 自动生成Excel报告 |
| 零依赖管理 / Zero-config Dependency | 自动管理测试依赖 |
| 零手动记录 / Zero-manual Recording | 自动收集测试结果 |
| 代码简洁 / Clean Code | 测试代码专注于业务逻辑 |
| 易于维护 / Easy Maintenance | 所有逻辑集中在钩子中 |

**关键要点 / Key Points:**
1. 所有报告和状态管理由钩子自动处理
2. 测试代码只需添加marker即可
3. 代码量减少约80%
4. 完全自动化，无需手动调用
