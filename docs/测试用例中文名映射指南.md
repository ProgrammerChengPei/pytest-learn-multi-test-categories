# 测试用例中文名映射指南

## 概述 / Overview

本文档介绍如何通过测试用例的中文名，将测试结果自动填充到Excel模板的指定单元格中，实现**用例设计和用例脚本的对应关系**。

This document describes how to automatically fill test results into specified Excel template cells through test case Chinese names, achieving **correspondence between test case design and test scripts**.

## 核心思想 / Core Idea

### 问题描述 / Problem Description

测试用例通常在Excel中设计并命名（如"测试abc"、"连接设备"等），而测试脚本的函数名通常是英文（如`test_abc`、`test_connect_device`）。如何让测试结果自动填充到Excel中对应的用例行？

Test cases are usually designed and named in Excel (e.g., "测试abc", "连接设备"), while test script function names are usually in English (e.g., `test_abc`, `test_connect_device`). How to automatically fill test results into the corresponding test case rows in Excel?

### 解决方案 / Solution

1. 为测试用例添加中文名
2. Excel模板中的"测试用例名称"列填入中文名
3. 配置JSON指定名称列和结果列
4. 测试运行时自动匹配名称并填充结果

1. Add Chinese name to test cases
2. Fill Chinese name in "Test Case Name" column in Excel template
3. Configure JSON to specify name column and result column
4. Automatically match names and fill results when tests run

## 快速开始 / Quick Start

### 步骤1: 为测试用例添加中文名 / Step 1: Add Chinese Name to Test Cases

#### 方式1: 使用装饰器 / Method 1: Use Decorator

```python
import pytest

@pytest.mark.flash
@pytest.mark.chinese_name("测试abc")
def test_abc():
    """测试abc"""
    assert True
```

#### 方式2: 使用中文文档字符串 / Method 2: Use Chinese Docstring

```python
@pytest.mark.interface
def test_api_login():
    """API登录测试"""
    assert True
```

**注意：** 文档字符串的第一行将被用作中文名。

**Note:** The first line of the docstring will be used as the Chinese name.

#### 方式3: 结合使用 / Method 3: Combined Use

```python
@pytest.mark.function
@pytest.mark.chinese_name("用户注册流程")
def test_user_registration():
    """用户注册流程测试 / User registration flow test"""
    assert True
```

### 步骤2: 准备Excel模板 / Step 2: Prepare Excel Template

在Excel模板的某个工作表中（如"测试用例"工作表），添加两列：

In a worksheet of the Excel template (e.g., "Test Cases" worksheet), add two columns:

| 列 / Column | 说明 / Description | 示例 / Example |
|------------|------------------|---------------|
| 测试用例名称 | 用例设计中文名 | "测试abc", "连接设备" |
| 测试结果 | 自动填充测试结果 | "通过", "失败", "跳过" |

**Excel模板示例：**

| 行号 | A | B | ... | J |
|------|---|---|-----|---|
| 1 | ... | 测试用例名称 | ... | 测试结果 |
| 2 | ... | 测试abc | ... | |
| 3 | ... | 连接设备 | ... | |
| 4 | ... | API登录测试 | ... | |

### 步骤3: 配置JSON / Step 3: Configure JSON

在 `configs/report_config_with_testcases.json` 中添加测试用例映射配置：

Add test case mapping configuration in `configs/report_config_with_testcases.json`:

```json
{
  "mappings": {
    "测试用例 / Test Cases": {
      "type": "testcase_mapping",
      "name_column": "B",
      "result_column": "J",
      "result_mappings": {
        "passed": "通过",
        "failed": "失败",
        "skipped": "跳过"
      }
    }
  }
}
```

**配置说明 / Configuration Description:**

| 字段 / Field | 说明 / Description | 示例 / Example |
|-------------|------------------|---------------|
| `type` | 必须是 `"testcase_mapping"` | `"testcase_mapping"` |
| `name_column` | 测试用例名称列的列字母 | `"B"` (B列) |
| `result_column` | 测试结果列的列字母 | `"J"` (J列) |
| `result_mappings` | 状态映射字典 | 见下表 |

**result_mappings 说明 / result_mappings Description:**

| 键 / Key | 值 / Value | 说明 / Description |
|---------|-----------|------------------|
| `passed` | "通过" | passed状态的中文显示 |
| `failed` | "失败" | failed状态的中文显示 |
| `skipped` | "跳过" | skipped状态的中文显示 |

## 最佳实践 / Best Practices

### 1. 命名规范 / Naming Conventions

**推荐的测试用例中文名 / Recommended Chinese Names:**

| 英文函数名 / English Function Name | 推荐中文名 / Recommended Chinese Name |
|--------------------------------|----------------------------------|
| `test_abc` | "测试abc" |
| `test_connect_device` | "连接设备" |
| `test_api_login` | "API登录测试" |
| `test_verify_version` | "验证版本号" |
| `test_performance_latency` | "延迟性能测试" |

**命名规则 / Naming Rules:**
- 使用简洁明了的中文
- 避免过长的描述（建议不超过20个字）
- 使用统一的命名风格
- 避免特殊字符

### 2. 使用装饰器还是文档字符串 / Decorator vs Docstring

**使用装饰器的场景 / When to Use Decorator:**
- 需要明确指定中文名
- 文档字符串包含其他内容
- 需要与其他测试用例名称一致

```python
@pytest.mark.chinese_name("API登录测试")
def test_api_login():
    """
    详细描述：
    1. 输入用户名和密码
    2. 点击登录按钮
    3. 验证登录成功
    """
    assert login("user", "pass")
```

**使用文档字符串的场景 / When to Use Docstring:**
- 文档字符串第一行就是中文名
- 希望保持代码简洁
- 函数名和中文名有明确的对应关系

```python
def test_api_login():
    """API登录测试"""
    assert login("user", "pass")
```

### 3. 确保名称唯一性 / Ensure Name Uniqueness

确保Excel模板中的测试用例名称唯一：

Ensure test case names in Excel template are unique:

```python
# ❌ 不推荐：重复的名称
@pytest.mark.chinese_name("测试登录")
def test_login(): pass

@pytest.mark.chinese_name("测试登录")  # 重复！
def test_login_admin(): pass

# ✅ 推荐：使用区分的名称
@pytest.mark.chinese_name("用户登录测试")
def test_login(): pass

@pytest.mark.chinese_name("管理员登录测试")
def test_login_admin(): pass
```

## 故障排查 / Troubleshooting

### 问题1: 测试结果未填充 / Issue 1: Test Results Not Filled

**可能原因 / Possible Causes:**
1. 测试用例没有中文名
2. Excel模板中的名称与中文名不匹配
3. JSON配置中的列字母错误

**解决方案 / Solutions:**

1. 检查测试是否添加了中文名：
```python
@pytest.mark.chinese_name("测试abc")
def test_abc():
    pass
```

2. 检查Excel模板中的名称是否完全一致（包括空格）

3. 验证JSON配置：
```json
{
  "name_column": "B",  # 确保是正确的列字母
  "result_column": "J"
}
```

### 问题2: 名称匹配不成功 / Issue 2: Name Matching Failed

**可能原因 / Possible Causes:**
- 名称前后有空格
- 全角/半角字符混用
- 大小写问题（中文不存在此问题）

**解决方案 / Solutions:**

使用`strip()`清理名称：

```python
# 在测试代码中使用clean名称
def test_api_login():
    """  API登录测试  """  # 前后有空格
    pass
```

系统会自动清理名称两端的空格，所以上述代码仍然可以正确匹配。

### 问题3: 没有中文名的测试 / Issue 3: Tests Without Chinese Name

**现象 / Symptom:**
测试用例没有中文名，不会填充到Excel的测试用例映射表中。

**解决方案 / Solutions:**

1. 为测试添加中文名
2. 或者在"测试详情"工作表中查看所有测试（包括没有中文名的）

### 问题4: 多个工作表映射冲突 / Issue 4: Multiple Worksheet Mapping Conflicts

**现象 / Symptom:**
同一个测试用例名称出现在多个工作表中，结果不一致。

**解决方案 / Solutions:**

这是正常情况，每个工作表会独立填充。如果希望只有一个工作表，请移除多余的映射配置。

## 工作原理 / How It Works

### 执行流程 / Execution Flow

```
1. 测试运行
   ↓
2. pytest_runtest_logreport 钩子执行
   ↓
3. 提取测试用例中文名
   ├─ 从 @pytest.mark.chinese_name 装饰器
   └─ 从文档字符串第一行
   ↓
4. 构建测试结果字典
   ├─ name: 函数名 (test_abc)
   ├─ chinese_name: 中文名 (测试abc)
   ├─ status: 状态 (passed)
   └─ 其他信息...
   ↓
5. 加载Excel模板
   ↓
6. 扫描工作表中的"测试用例名称"列
   ↓
7. 匹配中文名并填充到"测试结果"列
   ↓
8. 应用样式（绿色=通过，红色=失败）
   ↓
9. 保存Excel报告
```

### 数据结构 / Data Structure

**测试结果字典 / Test Result Dictionary:**

```python
{
    'name': 'test_abc',              # 函数名
    'chinese_name': '测试abc',       # 中文名
    'category': 'flash',             # 测试类型
    'status': 'passed',              # 状态
    'duration': 0.001,              # 耗时
    'message': '',                   # 消息
    'file': 'tests/xxx.py',          # 文件
    'line': 42,                     # 行号
    # ... 其他字段
}
```

**名称映射表 / Name Mapping Table:**

```python
{
    '测试abc': '通过',
    '连接设备': '通过',
    'API登录测试': '失败',
    # ...
}
```

## 总结 / Summary

1. **用例设计与脚本对应 / Test Case Design and Script Correspondence**
   - Excel中设计的用例名称直接映射到测试代码
   - 实现了用例设计和执行的无缝对接

2. **零配置映射 / Zero Configuration Mapping**
   - 只需添加中文名标记
   - 自动匹配并填充结果

3. **灵活配置 / Flexible Configuration**
   - 支持自定义列位置
   - 支持自定义状态映射
   - 支持多个工作表

4. **易于维护 / Easy to Maintain**
   - 测试用例名称集中管理
   - 修改模板无需改代码

### 关键要点 / Key Points

1. 使用 `@pytest.mark.chinese_name("中文名")` 或中文文档字符串第一行
2. Excel模板的"测试用例名称"列填写中文名
3. JSON配置指定名称列和结果列
4. 测试运行时自动匹配并填充结果

### 适用场景 / Applicable Scenarios

- ✅ 测试用例在Excel中设计并命名
- ✅ 需要将测试结果填充到设计的用例表中
- ✅ 用例中文名是统一的命名规范
- ✅ 需要保持用例设计和执行的一致性
