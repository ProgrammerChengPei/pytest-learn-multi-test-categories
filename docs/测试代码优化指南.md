# 测试代码优化指南 / Test Code Optimization Guide

## 概述 / Overview

本文档演示如何使用公共辅助函数和简化装饰器，减少重复代码，提高测试代码的可维护性。

This document demonstrates how to use common helper functions and simplified decorators to reduce code duplication and improve test code maintainability.

---

## 1. 公共辅助函数的使用 / Using Common Helper Functions

### 原始写法（不推荐）/ Original Approach (Not Recommended)

每个测试类型都实现相同的辅助函数：

Each test type implements the same helper functions:

```python
# tests/interface_tests/common/common.py
def send_and_receive(client, request, timeout=5.0):
    # 重复实现 / Duplicate implementation
    pass

# tests/function_tests/common/common.py
def send_and_receive(client, request, timeout=5.0):
    # 重复实现 / Duplicate implementation
    pass

# tests/performance_tests/common/common.py
def send_and_receive(client, request, timeout=5.0):
    # 重复实现 / Duplicate implementation
    pass
```

### 优化后的写法（推荐）/ Optimized Approach (Recommended)

使用 `tests/common/common.py` 中的公共辅助函数：

Use common helper functions from `tests/common/common.py`:

```python
# tests/interface_tests/test_interface.py
from tests.common.common import (
    send_and_receive,
    validate_response_structure,
    validate_response_status,
    compare_timestamps
)

class TestInterface:
    @pytest.mark.interface
    def test_interface_get_status(self, test_client):
        request = {
            "type": "request",
            "command": "get_status",
            "id": 1,
            "token": test_client.token
        }

        # 使用公共函数 / Use common function
        response = send_and_receive(test_client, request, timeout=10.0)

        # 验证结构 / Validate structure
        expected_fields = ["type", "id", "status", "server_time", "connections"]
        assert validate_response_structure(response, expected_fields)

        # 验证状态 / Validate status
        assert validate_response_status(response, "ok")
```

## 2. 简化的依赖管理 / Simplified Dependency Management

### 原始写法（冗长）/ Original Approach (Verbose)

每个测试都需要完整的依赖声明：

Each test requires complete dependency declaration:

```python
class TestInterface:
    @pytest.mark.interface
    @pytest.mark.dependency(name="test_interface_1", depends=["test_flash_complete"])
    def test_interface_1(self, test_state, flash_test_passed):
        if not flash_test_passed:
            pytest.skip("Flash test has not passed yet / 刷写测试未通过")
        # 测试代码 / Test code
        pass

    @pytest.mark.interface
    @pytest.mark.dependency(name="test_interface_2", depends=["test_flash_complete"])
    def test_interface_2(self, test_state, flash_test_passed):
        if not flash_test_passed:
            pytest.skip("Flash test has not passed yet / 刷写测试未通过")
        # 测试代码 / Test code
        pass

    @pytest.mark.interface
    @pytest.mark.dependency(name="test_interface_3", depends=["test_flash_complete"])
    def test_interface_3(self, test_state, flash_test_passed):
        if not flash_test_passed:
            pytest.skip("Flash test has not passed yet / 刷写测试未通过")
        # 测试代码 / Test code
        pass

    # ... 重复10次 / ... repeated 10 times
```

### 优化后的写法（简洁）/ Optimized Approach (Concise)

使用 `@require_flash_test` 装饰器：

Use `@require_flash_test` decorator:

```python
from tests.common.common import require_flash_test, interface_test_marker

class TestInterface:
    @interface_test_marker
    @require_flash_test
    def test_interface_1(self, test_state):
        # 测试代码 / Test code
        pass

    @interface_test_marker
    @require_flash_test
    def test_interface_2(self, test_state):
        # 测试代码 / Test code
        pass

    @interface_test_marker
    @require_flash_test
    def test_interface_3(self, test_state):
        # 测试代码 / Test code
        pass

    # ... 简洁明了 / ... concise and clear
```

## 3. 完整示例对比 / Complete Example Comparison

### 接口测试 / Interface Test

#### ❌ 原始写法（28行）/ Original Approach (28 lines)

```python
import pytest
from ..common.common import (
    send_and_receive,
    validate_response_structure,
    validate_response_status
)

class TestInterface:
    @pytest.mark.interface
    @pytest.mark.dependency(name="test_interface_get_status", depends=["test_flash_complete"])
    def test_interface_get_status(self, test_state, test_client, flash_test_passed):
        """
        Test get_status interface / 测试get_status接口
        """
        if not flash_test_passed:
            pytest.skip("Flash test has not passed yet / 刷写测试未通过")

        request = {
            "type": "request",
            "command": "get_status",
            "id": 1,
            "token": test_client.token
        }

        try:
            response = send_and_receive(test_client, request, timeout=10.0)

            # Validate structure
            expected_fields = ["type", "id", "status", "server_time", "connections"]
            assert validate_response_structure(response, expected_fields)

            # Validate status
            assert validate_response_status(response, "ok")

            print("✓ get_status interface test passed / ✓ get_status接口测试通过")

        except Exception as e:
            print(f"✗ get_status interface test failed: {e} / ✗ get_status接口测试失败: {e}")
            raise
```

#### ✅ 优化写法（18行）/ Optimized Approach (18 lines)

```python
import pytest
from tests.common.common import (
    interface_test_marker,
    require_flash_test,
    send_and_receive,
    validate_response_structure,
    validate_response_status
)

class TestInterface:
    @interface_test_marker
    @require_flash_test
    def test_interface_get_status(self, test_state, test_client):
        """
        Test get_status interface / 测试get_status接口

        Note: Automatically requires flash test to pass / 自动要求刷写测试通过
        """
        request = {
            "type": "request",
            "command": "get_status",
            "id": 1,
            "token": test_client.token
        }

        response = send_and_receive(test_client, request, timeout=10.0)

        # Validate structure
        expected_fields = ["type", "id", "status", "server_time", "connections"]
        assert validate_response_structure(response, expected_fields)

        # Validate status
        assert validate_response_status(response, "ok")

        print("✓ get_status interface test passed / ✓ get_status接口测试通过")
```

**代码行数减少 / Code reduction**: 28行 → 18行（减少36%）

### 性能测试 / Performance Test

#### ❌ 原始写法（35行）/ Original Approach (35 lines)

```python
import pytest
from ..common.common import measure_latency

class TestPerformance:
    @pytest.mark.performance
    @pytest.mark.dependency(name="test_performance_latency", depends=["test_function_complete"])
    def test_performance_latency(self, test_state, test_client, function_test_passed):
        """
        Test request latency performance / 测试请求延迟性能
        """
        if not function_test_passed:
            pytest.skip("Function test has not passed yet / 功能测试未通过")

        command = {
            "type": "request",
            "command": "health_check",
            "token": test_client.token
        }

        try:
            result = measure_latency(test_client, command, iterations=30)
            result.calculate_metrics()

            # Validate performance targets
            assert result.percentiles.get('p95', 0) < 1.0, \
                f"P95 latency should be < 1.0s / P95延迟应小于1.0s, got: {result.percentiles.get('p95', 0):.3f}s"

            print(f"✓ Latency performance test passed / ✓ 延迟性能测试通过 "
                  f"(avg: {result.percentiles.get('avg', 0):.3f}s, "
                  f"p95: {result.percentiles.get('p95', 0):.3f}s)")

        except Exception as e:
            print(f"✗ Latency performance test failed: {e} / ✗ 延迟性能测试失败: {e}")
            raise
```

#### ✅ 优化写法（22行）/ Optimized Approach (22 lines)

```python
import pytest
from tests.common.common import (
    performance_test_marker,
    require_function_test,
    assert_in_range
)
from tests.performance_tests.common.common import measure_latency

class TestPerformance:
    @performance_test_marker
    @require_function_test
    def test_performance_latency(self, test_state, test_client):
        """
        Test request latency performance / 测试请求延迟性能

        Note: Automatically requires function test to pass / 自动要求功能测试通过
        """
        command = {
            "type": "request",
            "command": "health_check",
            "token": test_client.token
        }

        result = measure_latency(test_client, command, iterations=30)
        result.calculate_metrics()

        # Validate performance targets using common assertion helper
        p95_latency = result.percentiles.get('p95', 0)
        assert_in_range(p95_latency, 0, 1.0, "P95 latency")

        print(f"✓ Latency performance test passed / ✓ 延迟性能测试通过 "
              f"(avg: {result.percentiles.get('avg', 0):.3f}s, "
              f"p95: {p95_latency:.3f}s)")
```

**代码行数减少 / Code reduction**: 35行 → 22行（减少37%）

"""

from tests.common.common import (
    interface_test_marker,

    validate_response_structure,

            "token": test_client.token

        expected_fields = ["type", "id", "status"]

    @interface_test_marker

        assert validate_response_structure(response, expected_fields)
        assert validate_response_status(response, "ok")
        assert response.get('original_text') == test_text

## 8. 最佳实践总结 / Best Practices Summary

### ✅ DO（推荐做法）

1. **使用公共辅助函数** - 减少重复代码
   - 从 `tests/common/common.py` 导入
   - 使用统一的验证和断言函数

2. **使用简化装饰器** - 简化依赖管理
   - 使用 `@require_flash_test` 替代冗长的依赖声明
   - 使用 `@interface_test_marker` 统一标记

3. **保持测试简洁** - 每个测试只做一件事
   - 避免在测试中重复实现辅助函数
   - 使用描述性的测试名称

### ❌ DON'T（避免做法）

1. **不要重复实现辅助函数**
   ```python
   # ❌ 错误 / Wrong
   def send_and_receive(...):  # 在每个测试类型中重复定义
       pass
   ```

2. **不要在每个测试中写完整的依赖声明**
   ```python
   # ❌ 错误 / Wrong
   @pytest.mark.dependency(depends=["test_flash_complete"])
   def test_x(self, test_state, flash_test_passed):
       if not flash_test_passed:
           pytest.skip("...")
   ```

3. **不要硬编码断言逻辑**
   ```python
   # ❌ 错误 / Wrong
   assert response.get('status') == 'ok', f"Expected ok, got {response.get('status')}"

   # ✅ 正确 / Correct
   from tests.common.common import validate_response_status
   assert validate_response_status(response, "ok")
   ```
