# 快速开始指南 / Quick Start Guide

## 1. 环境准备 / Environment Setup

```bash
# 克隆项目 / Clone project
cd pytest-viu-design

# 安装依赖 / Install dependencies
pip install -r requirements.txt
```

## 2. 启动测试服务器 / Start Test Server

```bash
# 在新终端中启动服务器 / Start server in new terminal
python src/server.py
```

服务器会在 `localhost:8080` 上监听。

Server will listen on `localhost:8080`.

## 3. 运行测试 / Run Tests

### 方式1: 使用测试脚本 / Method 1: Using Test Script

```bash
# 运行所有测试 / Run all tests
python run_tests.py --type all

# 仅运行刷写测试 / Run only flash tests
python run_tests.py --type flash

# 运行接口和功能测试 / Run interface and function tests
python run_tests.py --type interface
python run_tests.py --type function

# 运行性能测试 / Run performance tests
python run_tests.py --type performance
```

### 方式2: 直接使用pytest / Method 2: Using pytest Directly

```bash
# 运行所有测试 / Run all tests
pytest tests/ -v

# 运行特定类型测试 / Run specific test type
pytest tests/ -v -m flash
pytest tests/ -v -m interface
pytest tests/ -v -m function
pytest tests/ -v -m performance
```

## 4. 查看报告 / View Reports

测试完成后，在 `test_artifacts/` 目录下查看报告：

After tests complete, view reports in `test_artifacts/` directory:

- `pytest_report.html` - HTML格式的测试报告 / HTML format test report
- `pytest_report.xlsx` - Excel格式的测试报告 / Excel format test report
- `pytest.log` - 测试日志文件 / Test log file

## 5. 测试依赖说明 / Test Dependency Explanation

本框架使用 `pytest-dependency` 插件实现测试依赖，确保测试按正确顺序执行：

This framework uses `pytest-dependency` plugin to implement test dependencies, ensuring tests execute in correct order:

```
Flash Tests (刷写测试) → Interface Tests (接口测试) → Function Tests (功能测试) → Performance Tests (性能测试)
```

- ✅ 如果刷写测试通过，接口测试会执行
- ✅ 如果接口测试通过，功能测试会执行
- ✅ 如果功能测试通过，性能测试会执行
- ❌ 如果任一阶段失败，后续测试会被跳过

### 示例 / Example

```bash
# 场景1: 所有测试通过 / Scenario 1: All tests pass
$ python run_tests.py --type all
Flash tests: PASSED (5/5)
Interface tests: PASSED (5/5)
Function tests: PASSED (6/6)
Performance tests: PASSED (5/5)

# 场景2: 刷写测试失败 / Scenario 2: Flash test failed
$ python run_tests.py --type all
Flash tests: FAILED (2/5)
Interface tests: SKIPPED (depends on flash)
Function tests: SKIPPED (depends on interface)
Performance tests: SKIPPED (depends on function)
```

## 6. 常用命令 / Common Commands

### 带覆盖率的测试 / Test with Coverage

```bash
python run_tests.py --type all --coverage --coverage-threshold 95
```

### 并行测试 / Parallel Testing

```bash
python run_tests.py --type all --parallel --workers 4
```

### 详细日志 / Verbose Logging

```bash
pytest tests/ -vv --log-cli-level=DEBUG
```

### 停止在N次失败后 / Stop after N failures

```bash
pytest tests/ --maxfail=1
```

## 7. 故障排除 / Troubleshooting

### 问题1: 导入错误 / Issue 1: Import Error

```
ModuleNotFoundError: No module named 'pytest-dependency'
```

解决方法 / Solution:
```bash
pip install pytest-dependency
```

### 问题2: Excel报告未生成 / Issue 2: Excel Report Not Generated

解决方法 / Solution:
```bash
pip install openpyxl
```

### 问题3: 连接服务器失败 / Issue 3: Server Connection Failed

解决方法 / Solution:
```bash
# 确保服务器正在运行 / Ensure server is running
python src/server.py

# 检查配置文件 / Check config file
cat configs/config.json
```

## 8. 自定义测试 / Customizing Tests

### 添加新的刷写测试 / Add New Flash Test

编辑 `tests/flash_tests/test_flash.py`:

```python
@pytest.mark.flash
@pytest.mark.dependency(name="test_new_flash", depends=["test_flash_complete"])
def test_new_flash(self, test_state, test_client):
    """Your test here / 你的测试"""
    assert True
```

### 添加新的接口测试 / Add New Interface Test

编辑 `tests/interface_tests/test_interface.py`:

```python
@pytest.mark.interface
@pytest.mark.dependency(name="test_new_interface", depends=["test_interface_complete"])
def test_new_interface(self, test_state, test_client):
    """Your test here / 你的测试"""
    assert True
```

## 9. 配置说明 / Configuration

### 修改服务器配置 / Modify Server Configuration

编辑 `configs/config.json`:

```json
{
  "host": "localhost",
  "port": 8080,
  "token": "your-secure-token"
}
```

### 修改pytest配置 / Modify Pytest Configuration

编辑 `pytest.ini`:

```ini
[pytest]
addopts =
    -v
    --tb=short
    --html=test_artifacts/report.html
```

## 10. 性能测试说明 / Performance Test Notes

性能测试会消耗较多资源，建议：

Performance tests consume more resources, recommended:

- 在生产环境相似的配置上运行 / Run on production-like environment
- 确保服务器有足够资源 / Ensure server has sufficient resources
- 监控系统资源使用 / Monitor system resource usage
