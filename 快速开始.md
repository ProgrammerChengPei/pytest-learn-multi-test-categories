# 快速开始 / Quick Start

## 5步快速上手 / 5 Steps to Get Started

### 步骤1：安装依赖 / Step 1: Install Dependencies

```bash
cd e:/程培/pytest插件开发/pytest-viu-design
pip install -r requirements.txt
```

### 步骤2：生成Excel模板 / Step 2: Generate Excel Template

```bash
python scripts/create_template.py
```

模板会生成在 `templates/test_report_template.xlsx`。

Template will be generated at `templates/test_report_template.xlsx`.

### 步骤3：编辑Excel模板 / Step 3: Edit Excel Template

打开 `templates/test_report_template.xlsx`，在"测试用例 TestCases"工作表中填入测试用例中文名：

Open `templates/test_report_template.xlsx`, fill in Chinese names for test cases in the "测试用例 TestCases" sheet:

| 行号 | B列（测试用例名称） | J列（测试结果，自动填充） |
|------|---------------------|---------------------------|
| 2 | 测试abc | （自动填充） |
| 3 | 连接设备 | （自动填充） |
| 4 | API登录测试 | （自动填充） |

### 步骤4：编写测试代码 / Step 4: Write Test Code

创建测试文件，添加marker和中文名：

Create test file, add markers and Chinese names:

```python
# tests/my_tests.py
import pytest

@pytest.mark.flash
@pytest.mark.chinese_name("测试abc")
def test_abc():
    """测试abc"""
    assert True

@pytest.mark.flash
@pytest.mark.chinese_name("连接设备")
def test_connect_device():
    """连接设备"""
    assert True

@pytest.mark.interface
def test_api_login():
    """API登录测试"""
    assert True
```

### 步骤5：运行测试并查看报告 / Step 5: Run Tests and View Reports

```bash
pytest tests/my_tests.py -v
```

测试运行后，打开 `reports/test_report_YYYYMMDD_HHMMSS.xlsx` 查看报告。

After running tests, open `reports/test_report_YYYYMMDD_HHMMSS.xlsx` to view the report.

## 中文名映射方式 / Chinese Name Mapping Methods

### 方式1：使用装饰器 / Method 1: Use Decorator

```python
@pytest.mark.flash
@pytest.mark.chinese_name("测试abc")
def test_abc():
    assert True
```

### 方式2：使用文档字符串 / Method 2: Use Docstring

```python
@pytest.mark.interface
def test_api_login():
    """API登录测试"""
    assert True
```

## 测试依赖链 / Test Dependency Chain

Flash → Interface → Function → Performance

- Flash测试通过后，Interface测试才会运行
- Interface测试通过后，Function测试才会运行
- Function测试通过后，Performance测试才会运行

Flash tests run → Interface tests run → Function tests run → Performance tests run

## 常用命令 / Common Commands

```bash
# 运行所有测试 / Run all tests
pytest tests/ -v

# 运行特定测试文件 / Run specific test file
pytest tests/my_tests.py -v

# 运行特定类型测试 / Run specific type tests
pytest tests/ -v -m flash
pytest tests/ -v -m interface
pytest tests/ -v -m function
pytest tests/ -v -m performance

# 运行并生成覆盖率报告 / Run with coverage report
pytest tests/ --cov=src --cov-report=html
```
