### ✅ 问题1：测试详情工作表没有显示中文名 / Test Details Sheet Not Showing Chinese Names

**问题描述 / Description:**
- "测试详情 TestDetails"工作表中的"测试名称"列显示的是英文函数名而不是中文名
- The "Test Name" column in "测试详情 TestDetails" worksheet shows English function names instead of Chinese names

**根本原因 / Root Cause:**
- 配置文件中 `source` 字段设置为 `"name"` 而不是 `"chinese_name"`
- The `source` field in config file was set to `"name"` instead of `"chinese_name"`

**修复方案 / Solution:**
在 `configs/report_config.json` 和 `configs/report_config_with_testcases.json` 中修改配置：

Modified configuration in both `configs/report_config.json` and `configs/report_config_with_testcases.json`:

```json
"测试名称 / Test Name": {
  "col": "B",
  "source": "chinese_name",  // 修改为优先使用中文名 / Changed to prioritize Chinese name
  "fallback": "name",       // 如果没有中文名则使用函数名 / Use function name if no Chinese name
  "format": "string"
}
```

**代码修改 / Code Changes:**
在 `src/template_based_report.py` 的 `_fill_list_sheet` 方法中支持 `fallback` 字段：

Added support for `fallback` field in `_fill_list_sheet` method of `src/template_based_report.py`:

```python
# 获取值 / Get value
source = col_config.get('source')
fallback = col_config.get('fallback')

if source == 'index':
    value = index + 1
else:
    value = result.get(source, '')
    # 如果值不存在且配置了fallback，则使用fallback
    # If value doesn't exist and fallback is configured, use fallback
    if not value and fallback:
        value = result.get(fallback, '')
```

### ✅ 问题4：docstring字段在测试失败时显示错误信息 / Docstring Field Shows Error Message When Test Fails

**问题描述 / Description:**
- 当测试失败时，message字段显示的是错误信息，不是docstring
- When test fails, the message field shows error information, not the docstring

**已正确实现 / Already Correctly Implemented:**
在 `tests/conftest.py` 的 `pytest_runtest_logreport` 钩子中：

In the `pytest_runtest_logreport` hook in `tests/conftest.py`:

```python
# 提取docstring用于报告 / Extract docstring for reporting
docstring = ''
if test_node.obj and test_node.obj.__doc__:
    docstring = test_node.obj.__doc__.strip()

# 构建测试结果字典 / Build test result dictionary
test_result = {
    'name': report.nodeid.split('::')[-1],
    'category': test_type,
    'status': 'passed' if report.passed else 'failed' if report.failed else 'skipped',
    'duration': report.duration,
    'message': str(report.longrepr) if not report.passed else docstring,  # 关键
    'file': str(test_node.fspath),
    'line': getattr(test_node, 'lineno', 0) or 0
}
```

**逻辑说明 / Logic Explanation:**
- 测试**通过**时：`message` 字段存储完整的 docstring
- 测试**失败**时：`message` 字段存储错误信息（`report.longrepr`）
- When test **passes**: `message` field stores the full docstring
- When test **fails**: `message` field stores error information (`report.longrepr`)

### 2. 测试运行阶段 / Test Execution Phase

**数据收集 / Data Collection:**
1. 钩子 `pytest_runtest_logreport` 收集每个测试的结果
2. 提取中文名（从marker或docstring）
3. 提取docstring（用于说明列）
4. 构建测试结果字典

```python
    'chinese_name': '测试abc'
}
```

### 3. 报告生成阶段 / Report Generation Phase

**测试详情工作表 / Test Details Sheet:**
- 列表模式，填充所有测试结果
- B列优先显示中文名，如果没有则显示英文名
- List mode, fills all test results
- Column B prioritizes Chinese name, falls back to English name if not available

**测试用例工作表 / Test Cases Sheet:**
- 映射模式，根据B列的中文名查找对应测试
- 填充D列（测试结果）和E列（说明）
- Mapping mode, looks up corresponding tests by Chinese name in column B
- Fills column D (Test Result) and column E (Description)
