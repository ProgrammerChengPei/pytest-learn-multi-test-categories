# 测试用例中文名映射使用说明 / Test Case Chinese Name Mapping Usage Guide

## 功能说明 / Feature Description

这个功能允许通过测试用例的中文名，将测试结果和说明自动填充到Excel模板中，实现**用例设计（Excel）和用例脚本（Python）的对应关系**。

This feature allows automatic filling of test results and descriptions to Excel template through Chinese names of test cases, achieving **correspondence between test case design (Excel) and test scripts (Python)**.

---

## 工作流程 / Workflow

```
1. Excel模板中预先填好测试用例中文名（B列）
   ↓
2. 编写Python测试脚本，添加marker和中文名
   ↓
3. 运行测试
   ↓
4. 自动根据中文名匹配，填充结果到Excel
```

---

## 配置步骤 / Configuration Steps

### 步骤1：生成或编辑Excel模板 / Step 1: Generate or Edit Excel Template

Excel模板中需要包含"测试用例 TestCases"工作表，结构如下：

The Excel template should contain a "测试用例 TestCases" worksheet with the following structure:

| 列号 | 列名 | 说明 | 示例 |
|------|------|------|------|
| A | 序号 / No | 用例序号 | 1, 2, 3... |
| B | 测试用例名称 / Test Case Name | 用例中文名（**必须填**） | "测试abc", "连接设备" |
| C | 测试类型 / Test Type | 测试类型 | "Flash", "Interface" |
| D | 测试结果 / Test Result | 测试结果（**自动填充**） | "通过", "失败", "跳过" |
| E | 说明 / Description | 用例说明（**自动填充**） | 测试的docstring |

**重要 / Important:**
- B列（测试用例名称）需要**预先填好**，与Python测试脚本中的中文名对应
- The "Test Case Name" column (B) needs to be **pre-filled**, matching Chinese names in Python test scripts
- D列和E列会在测试运行后**自动填充**
- Columns D and E will be **automatically filled** after test execution

### 步骤2：配置JSON文件 / Step 2: Configure JSON File

在 `configs/report_config_with_testcases.json` 中配置映射关系：

Configure the mapping in `configs/report_config_with_testcases.json`:

```json
{
  "测试用例 TestCases": {
    "type": "testcase_mapping",
    "name_column": "B",          // 测试用例名称列 / Test case name column
    "result_column": "D",        // 测试结果列 / Test result column
    "docstring_column": "E",     // 说明列 / Description column
    "result_mappings": {
      "passed": "通过",
      "failed": "失败",
      "skipped": "跳过"
    }
  }
}
```

### 步骤3：编写测试代码 / Step 3: Write Test Code

#### 方法1：使用 `@pytest.mark.chinese_name` 装饰器

```python
import pytest

@pytest.mark.flash
@pytest.mark.chinese_name("测试abc")
def test_abc():
    """
    这个测试函数的docstring会自动填充到E列
    This docstring will be automatically filled to column E
    """
    assert True

@pytest.mark.flash
@pytest.mark.chinese_name("连接设备")
def test_connect_device():
    """
    连接设备测试
    """
    assert True
```

#### 方法2：使用中文文档字符串（第一行作为中文名）

```python
import pytest

@pytest.mark.interface
def test_api_login():
    """
    API登录测试
    
    注意：第一行"API登录测试"会被用作中文名匹配
    整个docstring会被填充到E列
    """
    assert True
```

## 工作原理 / How It Works

1. **测试收集阶段** / Test Collection Phase
   - 钩子 `pytest_runtest_logreport` 自动收集每个测试的结果
   - 提取测试的中文名（从marker或docstring）
   - 提取测试的docstring
   - Hook `pytest_runtest_logreport` automatically collects results of each test
   - Extracts Chinese name of test (from marker or docstring)
   - Extracts docstring of test

2. **结果映射阶段** / Result Mapping Phase
   - 构建 `test_result_map`: `{中文名: {status, docstring}}`
   - Builds `test_result_map`: `{Chinese name: {status, docstring}}`

3. **Excel填充阶段** / Excel Filling Phase
   - 遍历Excel模板的B列（测试用例名称列）
   - 对每个单元格的中文名，在 `test_result_map` 中查找
   - 将测试结果填充到D列，docstring填充到E列
   - 根据测试状态应用颜色样式（绿色=通过，红色=失败，黄色=跳过）
   - Traverses column B (test case name column) of Excel template
   - For Chinese name in each cell, looks up in `test_result_map`
   - Fills test result to column D, docstring to column E
   - Applies color styles based on test status (green=passed, red=failed, yellow=skipped)

## 常见问题 / FAQ

### Q1: 为什么测试结果没有填充到Excel？/ Why are test results not filled to Excel?

**可能原因 / Possible Causes:**
1. B列的中文名与测试脚本中的中文名不匹配
   - Chinese name in column B doesn't match Chinese name in test script
2. 测试用例没有中文名
   - Test case doesn't have Chinese name
3. JSON配置的列号不正确
   - Column numbers in JSON config are incorrect

**解决方法 / Solutions:**
1. 检查Excel B列的中文名是否与测试脚本中的完全一致（包括空格）
   - Check if Chinese name in Excel column B exactly matches test script (including spaces)
2. 确保测试用例使用了 `@pytest.mark.chinese_name()` 或有中文docstring
   - Ensure test case uses `@pytest.mark.chinese_name()` or has Chinese docstring
3. 检查 `configs/report_config_with_testcases.json` 中的列配置
   - Check column config in `configs/report_config_with_testcases.json`

### Q2: 可以自定义填充的列吗？/ Can I customize filled columns?

**可以 / Yes:**

修改 `configs/report_config_with_testcases.json`:

```json
{
  "测试用例 TestCases": {
    "type": "testcase_mapping",
    "name_column": "B",          // 修改为你的名称列 / Change to your name column
    "result_column": "K",        // 修改为你的结果列 / Change to your result column
    "docstring_column": "L",     // 修改为你的说明列 / Change to your description column
    "result_mappings": {
      "passed": "Pass",         // 自定义显示文本 / Customize display text
      "failed": "Fail",
      "skipped": "Skip"
    }
  }
}
```

### Q3: docstring和测试结果会冲突吗？/ Will docstring and test results conflict?

**不会 / No:**

- **测试结果**（通过/失败/跳过）只在测试**失败**时显示错误信息
- **docstring** 在测试**通过**时显示完整的文档字符串
- 如果测试失败，D列会显示"失败"，E列会显示错误信息
- 如果测试通过，D列会显示"通过"，E列会显示docstring

**Test results** (passed/failed/skipped) only show error messages when tests **fail**
**Docstring** shows full documentation when tests **pass**
If test fails: column D shows "失败", column E shows error message
If test passes: column D shows "通过", column E shows docstring

### Q4: 如果没有中文名会怎么样？/ What happens if there's no Chinese name?

测试结果仍然会收集，但不会填充到"测试用例 TestCases"工作表中。它会被记录到"测试详情 TestDetails"工作表。

Test results will still be collected, but won't be filled to "测试用例 TestCases" worksheet. They will be recorded in "测试详情 TestDetails" worksheet.

### conftest.py 关键代码 / Key Code in conftest.py

```python
# 提取docstring用于报告 / Extract docstring for reporting
docstring = ''
if test_node.obj and test_node.obj.__doc__:
    docstring = test_node.obj.__doc__.strip()

# 构建测试结果字典 / Build test result dictionary
test_result = {
    'name': report.nodeid.split('::')[-1],
    'category': test_type,
    'status': 'passed' if report.passed else 'failed' if report.failed else 'skipped',
    'duration': report.duration,
    'message': str(report.longrepr) if not report.passed else docstring,  # 关键：测试失败时用错误信息，通过时用docstring
    'file': str(test_node.fspath),
    'line': getattr(test_node, 'lineno', 0) or 0
}

# 提取中文名 / Extract Chinese name
chinese_name = None
chinese_name_marker = test_node.get_closest_marker('chinese_name')
if chinese_name_marker:
    chinese_name = chinese_name_marker.args[0] if chinese_name_marker.args else None

if not chinese_name and docstring:
    # 从docstring第一行提取中文名 / Extract Chinese name from first line of docstring
    if any('\u4e00' <= c <= '\u9fff' for c in docstring[:20]):
        chinese_name = docstring.split('\n')[0].strip()

if chinese_name:
    test_result['chinese_name'] = chinese_name
```

## 总结 / Summary

✅ **核心功能 / Core Function:**
1. 从Excel模板的B列读取测试用例中文名
2. 根据中文名在测试结果中查找对应测试
3. 将测试结果填充到D列，docstring填充到E列

✅ **使用要点 / Key Usage Points:**
1. Excel模板B列必须预先填好测试用例中文名
2. Python测试脚本需要提供中文名（marker或docstring）
3. 配置JSON文件指定映射的列号
4. 运行测试后结果自动填充

- 支持灵活的列配置
